## 🌐 关于

名字由 Glimmer 与 Verge 拼合而来。Verge 指临界，站在突破边缘；Glimmer 是微光，寻求突破的那一缕契机。我们以技术与工程探索未知，寻求那一缕微光

## 🚀 方向

工作站在突破的边缘上，以探索未知、寻求契机为主。AI、全栈等只是手段

- 🤖 **AI 与工作流**：将新能力纳入真实工作流，试出可促成突破的路径
- 🛠️ **全栈工程**：从前端到后端贯通实现，让试探能够持续落地
