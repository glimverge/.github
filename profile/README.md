## 🌐 关于

我们做极简、可靠的工具，也持续往技术前沿探。名字由 Glimmer 与 Verge 拼合而来。一个是微光，一个是临界。微光是细处刚露头的信号，临界是事情开始松动的边。工具与探索，大多落在这两处之间。

## 🚀 方向

目前主要沿着这几条线推进。

- 🤖 **AI 相关尝试**，看看把它揉进工作流后，能长出哪些真正能用的东西
- 🛠️ 全栈也会碰，从前端到后端，把工程做得更顺一些

仓库仍在陆续公开，新内容会先出现在 [GitHub](https://github.com/glimverge)
