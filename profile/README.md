## 🌐 关于

名字由 Glimmer 与 Verge 拼合而来。Glimmer 指微光，Verge 指临界。临界，指站在突破边缘；微光，是寻求突破的那一缕契机。我们据此做出极简可靠的工具，并沿这一边缘持续探索技术前沿。

## 🚀 方向

工作站在突破的边缘上。

- 🤖 **极简可靠的工具**：面向真实使用，少而稳，可长期维护
- 🔬 **技术前沿探索**：以 AI 融入工作流等方向为主，寻得可促成突破的契机

实现上覆盖从前端到后端的全栈工程。仓库仍在陆续公开，新内容会先出现在 [GitHub](https://github.com/glimverge)
