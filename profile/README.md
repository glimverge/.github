## 🌐 关于

Glimverge 是一间独立工作室，工作大多落在 AI 与软件相遇的地方

名字由 Glimmer 与 Verge 拼合而来。一个说微光，一个说临界。我们不追求铺开的强光，只希望在边界处留一点能辨路的亮

有想法便动手。有些很快可用，有些要反复打磨。规模不是眼下的第一目标。做之前，我们更在意它是否扣住本质，是否可以更少仍更稳，是否值得慢慢养下去

向下扎根，极简可靠，安静生长。工具可以很小，关键时刻靠得住就好

## 🚀 方向

目前主要沿着这几条线推进：

- 🤖 **AI 原生工具**，让 AI 进入开发流程里真正耗神的细处
- 🔗 **跨协议互联**，在异构系统之间搭一条尽量轻的通路
- 🛠️ 全栈也会碰，从前端到后端，把工程做得更顺一些

仓库仍在陆续公开，新内容会先出现在 [GitHub](https://github.com/glimverge)
