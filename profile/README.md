## 🌐 关于

一间游走在技术边缘的独立工作室。  
在 AI 与软件之间慢慢试，把零散念头收成小而靠谱的工具。

## 🚀 方向

眼下主要做这三件事：

- 🤖 **AI 原生工具** — 让 AI 真正进到日常开发的细枝末节里
- 🔗 **跨协议互联** — 给不同系统之间留一条轻便的路
- 🛠️ **全栈工程** — 从前到后，摸索更顺手的做法
