## 🌐 关于

名字由 Glimmer 与 Verge 拼合而来。Glimmer 指微光，Verge 指临界。微光是细处刚露头的信号，临界是事情开始松动的边。临界微光，意在清晰与未知的交界处寻得那一缕光。我们据此做出极简可靠的工具，并沿这一交界持续探索技术前沿。

## 🚀 方向

工作沿清晰与未知的交界展开。

- 🤖 **极简可靠的工具**：面向真实使用，少而稳，可长期维护
- 🔬 **技术前沿探索**：以 AI 融入工作流等方向为主，在尚未定型处寻找可用路径

实现上覆盖从前端到后端的全栈工程。仓库仍在陆续公开，新内容会先出现在 [GitHub](https://github.com/glimverge)
