## 🌐 关于

我们是一间很小的独立工作室，常在 AI 和软件挨着的地方晃。  
名字里那点意思也简单：Glimmer 是微光，Verge 是临界。不追大而全的亮，就想在边界上留一束能看清路的光。

想法来了就做。有的很快能用，有的要磨一阵。我们不太赶着上规模，先问自己三件事：这东西抠到本质了吗，能不能少一点还更稳，值不值得慢慢养。

所以做事大致就这几条。向下扎根，极简可靠，安静生长。小工具也行，关键时刻靠得住就好。

## 🚀 方向

眼下手里这几条线：

- 🤖 **AI 原生工具**，把 AI 塞进开发时真正费神的那些小步骤
- 🔗 **跨协议互联**，不同系统之间尽量少折腾就能通
- 🛠️ **全栈**也做，前端后端都摸，主要是想把工程做顺手

仓库还在陆续放出来，有新东西会先出现在 [GitHub](https://github.com/glimverge)。
