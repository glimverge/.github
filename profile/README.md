## 🌐 关于

我们是一间很小的独立工作室，常在 AI 和软件挨着的地方晃。  
想法来了就做，能用、够稳就行，不急着做大。

## 🚀 方向

| 🤖 AI 原生工具 | 🔗 跨协议互联 | 🛠️ 全栈工程 |
| :---: | :---: | :---: |
| 把 AI 塞进开发时真正费神的那些小步骤 | 不同系统之间尽量少折腾就能通 | 前端后端都摸，主要是想把工程做顺手 |

## 🧭 做事方式

| 向下扎根 | 极简可靠 | 安静生长 |
| :---: | :---: | :---: |
| 抠透本质，不做黑盒包装 | 少一点也没关系，先稳住 | 小步走，慢慢亮 |
